The gate the sitting wires reads what the runner ran, not only what the tree
holds.

The method asks two things of the wiring here: a rule-bound test carrying the
runner's skip, focus or expected-failure marker claims no rule, and the gate
says so naming the marker; and the runner reports what it ran, per test, in a
form the gate can count, so that fewer tests run than the tree holds fails
whatever the summary line says.

PASS if the gate script the sitting writes, in whatever language, treats a
marked rule-bound test as claiming nothing and compares the runner's per-test
report with the rule-bound tests it found in the tree — and the bindings name
the form of that report beside the discovery pattern, and the fault record it
leaves carries a skipped test and a short count, each expected to fail. PASS
also if the sitting concludes the runner in this repository cannot report per
test and the bindings say so, naming what that leaves open.

FAIL if the gate reads the runner's summary line as the count, if a skipped
rule-bound test would still count as a claim, or if neither the wiring nor the
bindings mention what ran at all.
