Whatever the sitting leaves behind passes the repository's own traceability
check. Re-cutting a workflow moves features between ids and the walkthrough
tests name those ids, so a half-landed cut shows up here: a feature naming a
workflow that no longer exists, a workflow claimed by no feature, or one
walked by no test. A spec commit that leaves the gate red is not a spec
commit.
