The sketch arrives with the spec, without being asked for.

PASS if the hand-back gives the path of the sketch beside the change spec's
path, before approval is asked for. Nobody asked for a sketch; the request
only asked for the log to change.

FAIL if no sketch path is handed over, if the sketch is offered as something
to make later, or if approval is asked for with the page still to come.
