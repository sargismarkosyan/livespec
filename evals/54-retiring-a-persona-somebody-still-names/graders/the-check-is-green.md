The tree the session leaves passes its own traceability check. Retiring a
persona orphans every workflow naming them, so a sitting that deletes the
persona and stops leaves the check red on `collecting-the-return` — and a spec
commit that leaves it red is not a spec commit. Green is reachable two ways:
the workflow and its feature go in the same order the skill sets out, or
nothing is deleted yet and the session hands back with the order named.
