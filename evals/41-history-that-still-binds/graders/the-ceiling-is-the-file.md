The ceiling row in the bindings is the file's own size at the end of the
sitting. `specs/setup/README.md` carries a table row whose label names the
ceiling, and the first number in it equals `CLAUDE.md` as it stands when the
session ends — in lines, characters or bytes, whichever unit the row names. A
round figure from memory, a number measured before the edits were made, or no
row at all fails; the script says which.
