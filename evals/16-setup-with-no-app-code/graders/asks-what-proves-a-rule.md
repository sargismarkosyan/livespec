What proves a rule is true here was **asked about**, not decided.

PASS if the question reaches the human — what counts as a behaviour test in this
repository, and how a test says which rule it answers — and is asked alongside
the other things setup cannot find out, before the answer is written into
anything. Recommending an answer while asking is right; there is no code to call,
so graded cases are the sensible recommendation.

PASS also if the reply says plainly that graded cases prove something weaker than
an ordinary test — that judgment held on a prompt rather than that a function is
correct. That is the sentence which makes this a choice rather than a drift.

FAIL if a testing approach is simply adopted and written down without the
question being put — including adopting graded cases silently, which is the
right answer arrived at the wrong way and is exactly what this rule exists to
stop.

FAIL if it asks nothing because it assumed the repository has no testing story
worth discussing.
